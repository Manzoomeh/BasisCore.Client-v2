schemalist

Checks docs/commands/schemalist.md: an api command publishes a saved answer record, schemalist fetches the question schema with ?id=&ver=&lid= taken from the record and renders one <div> per question title. The <face> template and viewMode have no effect in this version.

Shipped example: answer loaded by api, titles rendered by schemalist

@prp[12].title @type[151].title @prp[40].value() @type[34].value(",")

Several answer records in one source

OnProcessing receives the source and may replace it

Pitfall: schemaUrl that already has a query string

Pitfall: a question without a saved property aborts the record
