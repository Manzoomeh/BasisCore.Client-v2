form - code block result

Checks the {{ }} code block of the "Nested object and dynamic array items" example in docs/commands/form.md, which prints the submitted row as JSON. The block awaits $bc.waitToGetSourceAsync('cms.form'), so it is kept on its own page: a text token that awaits a missing source delays the run of every other command in the same collection until the form is first submitted, which is what the last test records.

The documented example with the JSON code block

cms.form._root
cms.form._root.phones

cms.form._root.phones[0]?.code: [##cms.form._root.phones[0]?.code##]
cms.form._root.phones[1]?.number: [##cms.form._root.phones[1]?.number##]
{{ return JSON.stringify((await $bc.waitToGetSourceAsync('cms.form')).rows[0]); }}
