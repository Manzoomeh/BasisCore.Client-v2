troubleshooting - AlaSQL not found

The "AlaSQL not found" rows of docs/troubleshooting.md: an empty host.dbLibPath throws Error in load 'alasql'. 'DbLibPath' not configure properly in host object., a path that is not served fails with the script's error event, and the fix (a reachable dbLibPath) makes a face filter work. Each case runs in its own runtime, in this order, because a successfully loaded alasql is global and would hide the two failures.
